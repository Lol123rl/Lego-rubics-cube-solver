The prime cuber is a LEGO Rubik's Cube solver. You just put the cube in, and it does the rest. I built it with the LEGO Spike Prime and coded it in the Python app provided. I used one kit to build it. the moters ether move the cube, twist it, or flip it. It also controls the color sensor. I learned that coding something so complex is vary time consuming. If I had time to improve it, it would be faster and more reliable.
